# Review Action

Review the active spec against the complete diff from `working`, including uncommitted changes. Check acceptance, correctness, scope, applicable verification, and the project documentation update matrix.

Report actionable findings with file locations and consequences. Separate an implementation defect from a wrong documented requirement; do not rewrite the contract to match a bug. State limitations of the available evidence.

Remain read-only unless fixes were requested. End with `Ready to complete` or `Needs changes`; neither verdict authorizes a commit or release.
